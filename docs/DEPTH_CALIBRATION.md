# RGB 카메라 뎁스 보정 알고리즘

## 적용 범위

- **0.6m 미만**: 보정 대상 아님. 해당 구간은 뎁스 값을 사용하지 않음 (카메라의 최소 센싱 거리 한계로 판단).
- **0.6m 이상**: 아래 선형 보정식 적용.

## 원본 측정 데이터

| 실제 거리(m) | 측정 뎁스(m) | 오차 |
|---|---|---|
| 0.6 | 0.63 | +0.03 |
| 0.8 | 0.84 | +0.04 |
| 0.9 | 0.94 | +0.04 |
| 1.1 | 1.20 | +0.10 |
| 1.4 | 1.58 | +0.18 |
| 1.7 | 2.00 | +0.30 |

오차가 거리에 비례해서 커지는 패턴 → 고정 오프셋이 아닌 **스케일(배율) 오차**가 주 원인. 1차 선형 회귀로 보정.

## 보정식

최소제곱 선형 회귀 (측정 뎁스 → 실제 거리):

```
보정된_거리 = 0.795 × 측정_뎁스 + 0.131
```

### 검증

| 측정 뎁스 | 보정 결과 | 실제 | 잔차 |
|---|---|---|---|
| 0.63 | 0.632 | 0.6 | +0.032 |
| 0.84 | 0.799 | 0.8 | -0.001 |
| 0.94 | 0.878 | 0.9 | -0.022 |
| 1.20 | 1.085 | 1.1 | -0.015 |
| 1.58 | 1.387 | 1.4 | -0.013 |
| 2.00 | 1.721 | 1.7 | +0.021 |

## 알고리즘 (의사코드)

```python
def correct_depth(raw_depth_m: float) -> float | None:
    if raw_depth_m < 0.6:
        return None  # 사용 안 함

    return 0.795 * raw_depth_m + 0.131
```

## 한계 및 주의사항

- 보정식은 6개 샘플 포인트로 도출한 것으로, 표본 수가 적어 신뢰 구간이 넓음.
- 특히 1.7m(가장 먼 샘플) 이후 구간은 외삽(extrapolation)이라 정확도 보장 안 됨.
- 정확도를 높이려면 0.6~2m 구간을 촘촘하게(0.1m 간격) 재측정해서 회귀식을 다시 산출할 것.
- 조명, 표면 재질(반사/투명 등)에 따라 오차 패턴이 달라질 수 있으므로, 실제 사용 환경과 동일한 조건에서 캘리브레이션 데이터를 수집해야 함.
